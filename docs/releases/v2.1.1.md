# v2.1.1 · 浏览器环境安装修复与 GPT-6.1 Terra 计费

受限 Docker 槽位即使已经下载浏览器运行包，也可能仍显示“浏览器环境不可用”。本版修复安装和状态检测的执行身份，并补齐 GPT-6.1 Terra 的内置价格，让环境准备和模型计费都有可核验的结果。

## 浏览器环境：以槽位用户执行

当容器关闭全部 Linux capabilities、槽位用户 home 权限为 0700 时，容器内的 root 也不能直接访问该目录。安装器现在使用槽位用户完成安装、检测、卸载和浏览器启动验证；KVM 保持原执行方式。

维护任务锁及取消标记按 UID 隔离，避免旧 root 任务留下的文件阻塞操作。安装不执行账号登录，不开启手动关闭的调度；卸载保留浏览器会话资料、缓存和配置，不放宽目录权限或增加容器 capabilities。

已在隔离、断网、512 MiB 内存的受限 Debian 12 测试容器中验证安装、内嵌测试页启动、状态检测、卸载和重装，并检查会话资料及 0700 权限保持不变。该修复也已作为生产补丁完成实际安装验收，未使用导入账号登录。

## GPT-6.1 Terra：按官方价格计费

标准模式，单位为美元 / 每百万 Token：

| 项目 | 价格 |
| --- | ---: |
| 输入 | $1.00 |
| 缓存读取 | $0.05 |
| 输出 | $5.00 |
| 默认缓存写入（30 分钟保留） | $1.25 |

**$0.050 = $0.05，缓存读取为输入价格的 5%；不是 $0.5。**

补齐 Flex（标准价的 50%）、Fast（标准价的 2 倍），以及超过 272K 输入时的全请求价格：输入与缓存为 2 倍、输出为 1.5 倍。测试覆盖缓存读写分摊、272K 边界和不同服务档位。

来源：[OpenAI GPT-6.1 Terra 模型文档](https://developers.openai.com/api/docs/models/gpt-6.1-terra)，核验日期 2026-10-27。内置价格作为兜底，保留现有自定义覆盖及动态价格源的优先级。本版没有新增 12 小时缓存保留期的识别和计费能力。
