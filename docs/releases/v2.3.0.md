# vm2api v2.3.0

本版补齐完整备份与恢复链路，新增 **COS / OSS / S3 云端归档、上传后本地清理、存储桶扫描与异机恢复**。账号、槽位与运维资料统一保护，降低对宿主机长期保存备份的依赖。

## 完整备份与恢复

- **恢复业务状态**：一致数据库快照、账号池与凭据、账号绑定、槽位内嵌套授权、浏览器 profiles/config、注册记录，以及质量运维配置与执行记录一并保存。浏览器 SQLite 使用逻辑快照，保留已提交 WAL 中的数据。
- **部署参考单独保存**：归档包含源机环境和 Compose 等参考文件，恢复至独立目录供人工核对，不覆盖目标机正在使用的部署配置。
- **可恢复性预检**：恢复前核验完整 SHA-256、密码解密认证、归档路径与清单、数据库完整性、迁移兼容性及凭据可解密性。源凭据重新加密为目标实例密钥。
- **维护与回滚保护**：预检后暂停请求和后台写入，创建恢复前快照，再替换资料并重绑运行时服务。失败自动回滚；回滚未完成时保留维护标记及证据，阻止直接正常启动。

## 存储桶与本地空间

支持腾讯云 COS、阿里云 OSS 的 S3 兼容入口，以及其他 S3 兼容服务。提供连接测试、分段上传、失败重试和按份数保留。

云备份使用 **scrypt + AES-256-GCM**，需设置至少 12 位的独立备份密码。访问密钥及密码加密存储，接口不回显；密码必须在宿主机之外另行保存，历史归档需要对应密码。

上传核对对象长度、SHA-256 元数据及可读取的独立索引后，本地副本可选 **立即清理** 或 **最多保留 24 小时**。上传失败时保留唯一副本并重试；修改桶或前缀后，不会将旧失败备份自动上传到另一个目的地。创建和恢复仍需要临时磁盘空间。

## 扫描存储桶恢复

在「设置 → 备份 → 从存储桶恢复」扫描备份，按时间选择后下载、预检并恢复。**新实例没有原机本地备份记录也可以恢复**：配置原桶、前缀、访问密钥和备份密码即可读取独立索引。

扫描支持分页和异常索引提示；恢复重新计算整个下载文件的 SHA-256。上传阶段核对元数据与长度，不将其表述为完整回读验证。

## 升级与操作要求

- 镜像：`ghcr.io/zhang2580384/vm2api:v2.3.0`，提供 amd64 / arm64 多架构版本。
- 新增数据库迁移 **043_backup_remote.sql**。升级前保留可验证备份；回退旧程序时恢复匹配版本的数据。
- **恢复前全部槽位必须关机**，并结束登录、注册、远程浏览器及后台任务。只关闭调度不足以恢复；恢复后的槽位保持关机，检查配置后再手动启动。
- 浏览器运行包、缓存、面板登录会话、虚拟机磁盘及未挂载的远程节点资料不在归档内；本功能不是跨集群整机镜像。普通本地 `.tar.gz` 未强制加密，应按敏感凭据资料保管。
- 普通在线备份不构成所有业务文件与数据库的全局事务；要求严格业务时间点时，先静置业务和后台任务再备份。

完整范围、服务商配置、空间需求及中断恢复方法见 [备份与恢复文档](https://github.com/zhang2580384/vm2api/blob/v2.3.0/docs/BACKUP_RESTORE.md)。
