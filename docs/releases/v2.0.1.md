# vm2api v2.0.1

- 登录和远程浏览器使用目标槽位配置的语言、时区，不再固定 en-US；旧 profile 重用时同样更新。
- 网络沿用目标槽位已绑定的透明出口；浏览器忽略额外系统代理，不叠加第二层代理。实际槽位网络与绑定不一致时拒绝登录。
- 旧槽位缺少语言、时区字段时从槽内环境读取；无效配置拒绝启动。C/POSIX 使用浏览器英文约定。
- 导入只加密保存，绑定不执行登录；首次登录仍需手动点击。浏览器运行时前提与 v2.0.0 相同。

镜像：`ghcr.io/zhang2580384/vm2api:v2.0.1`（amd64/arm64）。上游基线仍为 v1.3.226。

OAuth 最后换票保留控制面经槽位对应出口的既有路径。此次发布不自动部署生产服务器，不修改槽位、代理或浏览器 profile 数据。
