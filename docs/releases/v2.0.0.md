# vm2api v2.0.0

首个自维护发行版，基于官方 v1.3.226，发布与更新源切换到 `zhang2580384/vm2api`。

- 合入 #665：GPT 等待队列按请求能使用的账号唤醒，减少满载时反复选槽和 CPU 空转。
- 补齐调度设置改变后的有界广播唤醒，避免无账号唤醒在满载队列中反复传递。
- 提取 ohno1007/f651215 的账号密码导入功能：加密账号池、租户隔离、槽位绑定、密码/TOTP/微软邮箱登录和人工验证码接管。导入和绑定不执行登录。
- 版本接口和关于页面显示上游基线。检查更新、安装脚本和默认控制面镜像使用自有仓库。
- 保留 v1.3.226 已包含的 IPv6 控制面查询兼容性，CLI/kernel payload 继续按原基线独立校验固定。

控制面镜像：`ghcr.io/zhang2580384/vm2api:v2.0.0`，另有 `v2.0.0-amd64` / `v2.0.0-arm64`。

首次从官方版本迁移需要明确切换镜像仓库，此后面板才从本仓库检查更新。实际密码登录需要匹配槽位系统的浏览器运行时，尤其只读槽位须预先准备 portable 包；导入和绑定无需浏览器。运行包准备方法、补丁来源及生产切换注意事项见 [维护说明](https://github.com/zhang2580384/vm2api/blob/main/docs/MAINTENANCE.md)。

不覆盖 `.env`、`routing.json`、`vms/`、`data/` 或现有反向代理配置；不重建业务槽位。本次源码及发布不自动部署生产服务器。
