# v2.4.1 · 槽内原生授权，按需浏览器与低配资源管理

**让授权真正回到槽位，让浏览器只在需要时占用资源。**

本版把显式登录和远程操作切换为槽内原生 Chromium：从网络出口到语言、时区和会话资料都跟随所选槽位，人工操作通过私有图形显示直接送达浏览器。配合按需安装、授权成功后卸载程序及临时资源恢复，减少长期运行浏览器给低配服务器带来的负担。

## 本次升级重点

- **原生浏览器，真实远程操作。** 槽内直接启动 Chromium，私有 Xvfb 提供画面，X11/XTEST 传递鼠标和键盘，支持中文输入及双向文字剪贴板。显式登录窗口不连接 Playwright、CDP 或浏览器调试端口；不覆盖浏览器指纹属性。
- **环境跟随槽位。** 授权沿用当前槽位的代理出口、网络、语言、时区及独立 profile。会话不搬到面板机或操作者电脑，静置槽位仍允许明确发起的手动操作。
- **浏览器按需准备，用后释放。** 登录自动检查并准备匹配系统的 r5 运行包，旧包按需升级，同类系统复用 SHA-256 校验缓存。OAuth 凭据确认保存后卸载槽内浏览器运行文件，保留会话、缓存、配置和账号凭据；清理异常单独提示，不将已保存的授权误报为失败。
- **低配 Docker 资源闭环。** 浏览器任务将低于 1536 MiB 的有限内存上限临时提高至该值，CPU 限制为最多 1 核；更高或无限内存、原有更严格 CPU 限额保持。任务结束、进程退出后恢复原限制，异常中断留下可核对的资源租约，不重建槽位、不改持久规格或调度。
- **修复域名转发继承。** 出口以代理池配置为准，绑定和编辑同步槽位快照，修正启动及恢复时沿用旧开关的问题。保留多选、全选当前筛选结果、批量编辑、逐项结果和失败项重试。

## 已有能力完整保留

账号池与加密凭据、注册辅助、手动验证码操作、静置时手动登录、剪贴板、质量运维真实检测与定时任务、糖果题独立恢复调度开关、完整备份、COS / OSS / S3 扫描恢复、#665 按账号队列唤醒，以及自有更新源和社区信息继续保留。

自动注册及后台自动重登仍使用原有自动流程；注册完成后的 OAuth 确认窗口使用原生人工授权。导入和绑定本身不执行登录。浏览器和维护任务继续实行全局单任务互斥，繁忙时明确返回提示，目前没有排队机制。

## 升级与资源说明

1. 升级前按现有版本支持的方式准备可恢复备份，保留 Compose、override、环境配置及持久数据挂载。
2. 使用本仓库 `v2.4.1` 正式镜像，或通过面板检查更新；首次登录准备 r5 环境可能需要下载和构建依赖。
3. 浏览器资源的 1536 MiB 是整个容器的临时内存上限，不是额外物理内存预留，也不保证任意页面负载都不会 OOM。KVM 不自动调整规格，需自行预留资源。
4. 授权成功后的卸载仅移除槽内运行文件。宿主仍保留同系统组合的共享压缩缓存；再次登录可复用。集群节点首次安装仍经面板传包，尚未实现节点间共享目录，需考虑数百 MiB 的传输。

本版没有新增数据库迁移或 payload 变更。选择性上游基线仍为 **v1.4.006**；Claude 协议继续保持 **v1.3.226 / 本分支 v2.0.2** 兼容实现，暂缓项目及原因见 [上游同步记录](https://github.com/zhang2580384/vm2api/blob/v2.4.1/docs/UPSTREAM_SYNC_1.4.006.md)。

控制面镜像：`ghcr.io/zhang2580384/vm2api:v2.4.1`（amd64 / arm64 多架构），也提供 `v2.4.1-amd64` 与 `v2.4.1-arm64` 单架构标签。Release 无后缀附件为 linux amd64，`-linux-arm64` 后缀为 ARM64 原生 helper；槽位 kernel / CLI 仍只有 amd64，ARM64 主机经 QEMU 运行。部署及架构限制见 [部署指南](https://github.com/zhang2580384/vm2api/blob/v2.4.1/docs/DEPLOY.md)和 [ARM64 说明](https://github.com/zhang2580384/vm2api/blob/v2.4.1/docs/ARM64.md)。

## 验证范围与边界

Debian 12 / Python 3.11 / amd64、Ubuntu 24.04 / Python 3.12 / amd64 已通过隔离离线测试，覆盖原生画面、点击、中文、剪贴板、语言时区、虚构 OAuth 回调、supervisor、资源恢复以及安装、取消、卸载和重装；测试完成后没有遗留 Chromium/Xvfb。运行包验证复用了既有 Chromium 和图形二进制并重新打包，不能等同于全量 builder 从零构建验收。完整记录见 [浏览器环境文档](https://github.com/zhang2580384/vm2api/blob/v2.4.1/docs/BROWSER_ENVIRONMENT.md)。其他发行版组合、arm64 浏览器运行包、KVM 和远程集群尚未实机验收。

生产候选版本已完成部署和健康检查，操作者报告复测通过。隔离自动测试使用虚构数据，不访问真实账号、不调用实际模型、不执行第三方人机验证。**图形环境和点击正常不等于 CF 必定通过**；本版不提供验证码破解或反检测必过承诺。
