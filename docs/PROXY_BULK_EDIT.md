# 代理批量编辑

管理员进入「代理」页面，可勾选单条代理或「全选当前筛选结果」，再点击「批量编辑」，统一开启或关闭域名转发。

- 可先按地址、名称、槽位或地区筛选。搜索包含已满、禁用和失效的节点；选择空位时使用「有空位」筛选。
- 全选只作用于当前筛选结果。本地出口不参与选择。切换筛选会保留之前勾选的代理，工具栏会显示筛选外的已选数量；点击「清空选择」可全部取消。
- 应用前展示完整选择范围、原设置、目标设置及涉及的槽位数量。批量操作只提交 `domain_forward` 字段，代理地址、账密、绑定和调度设置保持原值。
- 逐条应用，设置相同的代理自动跳过。处理期间保持页面打开；单条失败后继续处理其余代理，并保留具体原因。
- 设置已保存但出口启动失败时会明确提示。可以单独重试未成功项；后端会重新确保出口进程就绪，健康且配置匹配的进程会被复用。

域名转发根据出口观察到的唯一 DNS 应答，将透明 TCP 的目标交给同一代理按域名连接。该功能不强制 IPv6，没有唯一 DNS 关联时仍可能使用原 IP。变更已绑定代理的设置会重启相应出口转发进程，现有连接可能短暂中断，宜在空闲时应用。

验证包含批量请求顺序、设置相同跳过、本地出口排除、单项失败继续、失败项重试、关闭开关及只提交目标字段的回归测试，以及前端类型检查、构建和代码检查。
