## 合并后的兼容修复

上游软暂停状态 `paused` 表示已开机但不接单。浏览器入口和前端按钮识别此状态，实际容器运行情况与出口网络仍由运行时检查；`runtime.stopped` 明确拒绝操作。

手动 OAuth 成功后，只清除凭据相关的不可调度标记，保留 `schedule_off`、代理故障及维护 hold。新增测试使用虚构凭据和磁盘槽位记录，验证成功持久化与调度保护，不访问账号提供方。

前端预览的常驻提示词插入规则与新版后端一致：零注入不凭空创建 agent 块；旧保存模板的 scope 迁移仍有独立覆盖。更新对应旧模板断言及上游新增文件格式。
